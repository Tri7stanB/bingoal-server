`999001.json` est un match d'exemple au format API-Football, inspiré de Lille-Marseille
(Ligue 1, 20 mai 2023) mais modifié pour couvrir les cas limites : but VAR annulé,
rouge annulé par la VAR, penalty, remplaçant buteur (Bayo, 2020, absent des titulaires),
doublé et but dans les arrêts de jeu (David, 90+3). Ce ne sont pas les vraies données du match.
